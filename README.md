# kiddyproof — downloads

**Toddler-proof your Mac.** Hand over the keyboard, keep your work.

This repo hosts the public binaries and release feed for
[kiddyproof.app](https://kiddyproof.app). The source is private.

## Install with Homebrew

```sh
brew install --cask brothaakhee/tap/kiddyproof
```

Or download the DMG directly:

**[⬇ Download the latest DMG](https://github.com/brothaakhee/kiddyproof-releases/releases/latest/download/kiddyproof.dmg)**

- macOS 14 Sonoma or later, Apple Silicon
- 7-day free trial, then a one-time license — [kiddyproof.app/buy](https://kiddyproof.app/buy)
- Developer-ID signed · auto-updates via Sparkle

**Install:** open the DMG, drag kiddyproof to Applications, launch it, grant
Accessibility when prompted, relaunch, then press **⌃⌥⌘K** to enter kid mode.
Exit any time by holding **⌃⌥⌘** (or the bottom-left screen corner) for 3 seconds.
